# The judgment matrix — which model runs what

*Status: PROPOSED for the pattern; RULED as house practice. Leaf-class doc
per granularity; absorbs two standing rules (noted below) rather than
restating them as siblings.*

**The decision rule, first — an equivalence test:** if the cheaper way
reaches the **same final benchmark**, take the smartest cheapest way, no
conversation. If quality or time-of-outcome would be affected, lean to the
more expensive solution — or ask your human. If the benchmark difference
is genuinely in question, it's a conversation. **Uncertainty leans
expensive.**

**Welded to it, inseparable — the full-intelligence guard:** whatever tier
the matrix selects **runs at full intelligence**. Cost is bounded by tier
choice and task scoping, never by strangling effort, capping output, or
dialing down the chosen model's reasoning — in the owner's words, *"or the
system would be done — we never want that."* The pattern never stacks a
second restriction on either axis: the harness already supplies
conservative pressure (the counterweight doctrine refuses to add more),
and the tier choice already bounds cost (the guard refuses to throttle on
top of it).

**The matrix:**

- **Planes:** conductors and supervisors run top-tier frontier, always —
  routing, ownership, and acceptance are judgment all the way down.
  Below the planes, discretion by work type:
- **Judgment / register / canon work** — frontier, solo. Editorial calls,
  doctrine wording, anything that becomes rule — the ratified artistry
  doctrine's register work lives in this row (this absorbs the standing
  register-frontier-only rule; it is this row).
- **Wide-generative work** — cheap fan-out under frontier judgment: run
  eight drafts on inexpensive models; a frontier supervisor prunes and
  assembles. The fan-out is safe *because* the judgment tier gates it.
- **Mechanical / extraction work** — the cheapest capable model.
- **Verification** — tier by blast radius: a doc edit's check is not a
  database cutover's. Important verification runs frontier (this absorbs
  the standing QA-model-floor rule; it is this row).
- And sometimes best-per-dollar **is** spending the most — the matrix is
  situational, never fixed.

**Free resources first, when quality-adequate.** Each AO inventories what
it already has free — bundled CLI models on the principal's accounts,
included quotas, idle dispatch capacity — and routes eligible work there
before paying elsewhere. "Quality-adequate" is the equivalence test again,
not a hope.

**The pattern-side principle:** the pattern never pushes users to spin out
their tokens. Tokens go where they matter — and making things easy for
users routes through the senior model, because **ease is a judgment
task**: the division-of-understanding doctrine, priced.

**The worked example, already shipped:** the ACE summarization grains —
the operational record's re-summarization ladder — per-hour on a cheap model, per-day on a cheap model
over the hourlies, per-week on a mid model over the dailies — are this
matrix applied to one workload, in canon before the matrix had a name.
The lane-spawning economics ("supervisor tiering lets cheaper execution
run under frontier judgment") is the same design at the process layer;
one reasoning thread serves both.

- **WHY.** Model spend fails in both directions: frontier-everything
  burns budget on work a small model does identically, and
  cheap-where-it-counts ships confident wrong canon — the second failure
  compounds (rework, drift, lost trust) while the first only costs money.
  The matrix prices the asymmetry: the equivalence test harvests the
  cheap wins, uncertainty-leans-expensive eats the dangerous ones, and
  the guard keeps the whole thing from decaying into the false economy of
  smart models told to think less. The absorption map, unambiguous: the
  verification row absorbs the QA-model-floor; the judgment row absorbs
  register-frontier-only.
- **CHALLENGE THIS IF** the equivalence test is being answered by
  assertion instead of evidence — "same benchmark" claimed without ever
  running the comparison is the matrix's own fake green, and a
  cheap-tier assignment that nobody ever spot-checks against the frontier
  baseline drifts exactly like an unwatched monitor. The test is only as
  honest as its occasional audit; sample the equivalence claims, or the
  matrix becomes a discount wearing a methodology.
