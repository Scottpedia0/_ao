# Lineage — the Go2 protocol and its receipts

**SAO is the AI application of the [Go2 protocol](https://go2.io).** Go2
spent eight years running a simple protocol on real work: watch the work
where it happens, turn the data into proof of work — not vibes, not
self-reports — and wrap it in coaching and accountability so people get
better and get what they've earned. The protocol has five pillars, and they
are exactly what they sound like: We Show Up. We Speak Up. We Fuck Up. We
Trust the Process. We Create Our Own Opportunities. Go2 was drawing its
values as named robots back in 2018 — "Hi, I'm Accountability bot. I embody
core value #1, 'Show up'!" ([the 2018 deck,
PDF](https://moran.bot/sao/evidence/go2bots-2018.pdf)) — and SAO runs the
same protocol on AI agents: every action lands as a receipt, no agent
grades its own homework, and the coaching layer helps your agents help
themselves while the record stays yours — portable across every model
vendor. Go2 wrote the trajectory down in 2022: the pivot from human
coaching supported by tech to tech supported by human coaching. SAO is that
sentence, shipped.

The graded receipts behind that story follow, verbatim — read the dating
caveat before quoting the deck.

### What the deck contains (as exported)

Eight slides. Four named bot characters, each explicitly embodying a Go2 core
value: **Accountability bot** ("I embody core value #1, 'Show up'!"),
**Unitybot** (core values 2 and 3, "ask questions" and "say what you think"),
**Taskbot** ("I live for core value 4 'Trust the process'"), **Trainer bot**
("non-living embodiment of core value #5 'Invest in people'"). A composite
slide renders the four bots in an 8-bit platformer level ("The Go2bots are
here to help you reach new high scores!").

Title-slide fine print, verbatim (established as present; wording not datable
to 2018): "*Cartoon representations of concepts, automations and AI are only
cheesy/lame if you have given up on all of your childhood dreams".
